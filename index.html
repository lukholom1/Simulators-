Before you flash

  • Read the help file that comes with the update tool.
  • Remove the SIM card and back up your personal information.
  • Install the USB drivers first, then choose the right software version.
  • Don't plug in or remove any USB device until the update finishes.

These four points come from the update tool's own start screen.

How to flash

  1. Install the USB drivers on a Windows PC.
  2. Download your build and unzip the update tool. Keep the .bin file in a folder of its own.
  3. Start the update tool. Under Software Version, select the folder that holds the .bin.
  4. Connect the hotspot over USB. The tool lists it on a line and shows "Device is ready."
  5. Set the update option to Download, right-click the device, and choose Start Update.
  6. Wait for "Update successfully!" before you unplug anything. If you see "Update fail!", run the update again.

The tool also has NV backup and NV restore modes. Run a backup before you update if you want to be able to restore the device's NV data.
